// WHAT EVERY REPOSITORY GETS

A few lines of caller in, the organisation's whole delivery pipeline out.

Thin callers

A repository keeps only triggers, permissions and a SHA pin. Logic, action pins and fixes come from the library, and Renovate moves the pin on every release.

mise is the boundary

Workflows run mise run lint, build, test. Every toolchain is checksum-verified from the repository's pins, the same versions as on your laptop.

Signatures preserved

/merge and /auto-merge fast-forward main, so the commits that land are the ones the author signed. The only check added to a PR is a single ack job.

Releases that publish last

GoReleaser fills a draft with signed, notarized, attested assets. The release is published only when every step has succeeded. Docs go to Pages from the same run.

Short-lived App tokens

Privileged work runs on GitHub App tokens minted per job, scoped down to the permissions and repositories that step needs. They expire within the hour.

Renovate per repository

The org bot runs against each repository on its own hourly schedule, and runs immediately when you tick a checkbox on the dashboard or a PR.
